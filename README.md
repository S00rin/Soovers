# SooVers industrial academy demo

[Open the course reader](https://soovers-academy-demo.nutmegtern65.chatgpt.site/#ics) with the owning ChatGPT account. No academy registration is required; progress and lesson notes stay in this browser. Placement and all knowledge checks are optional.

The academy now contains 42 Persian lessons across 34 chapter guides: ten lessons adapted from the supplied student book plus 32 original guides with worked examples and evidence cases, including two capstones. Reading, experiments and saved workbooks share one continuous desktop/mobile path. Search chapters, adjust reading size or open reference material without leaving the lesson.

The original English reading covers Book B Chapters 1–2; later guides are academy-authored. The reference curriculum's 816 classroom hours are not a duration claim for this web edition. Includes three interactive workbenches, twelve equipment profiles and a 102-term glossary.

Use `#ics/lesson/drawings` for a direct lesson, `#demo` for F5 and `#tower` for the campus. The fifteen Persian campus narration files are preserved.
