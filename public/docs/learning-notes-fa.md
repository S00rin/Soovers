# یادداشت مرجع درس‌های SooVers 0.4

## pfSense

برای یک اتصال تازه، قواعد رابط ورودی به‌ترتیب بررسی می‌شوند. قانون عبور باعث ساخت وضعیت اتصال می‌شود و بسته‌های بعدی همان اتصال با وضعیت تطبیق داده می‌شوند. مدل آموزشی این دمو NAT و قواعد Floating را برای تمرکز بر جریان پایه کنار گذاشته است. مدل سه‌بعدی نمایش عملکرد است، نه چیدمان مدار یک سخت‌افزار خاص.

منبع: https://github.com/pfsense/docs/blob/master/source/firewall/firewall-rule-basics.rst

## Suricata

حسگر در حالت IDS ترافیک را مشاهده و هشدار ثبت می‌کند. برای مسدودکردن باید در حالت مناسب IPS و در مسیر عبور پیکربندی شود. خروجی EVE رویدادها، هشدارها و فرادادهٔ جریان را به صورت JSON نگه می‌دارد؛ flow_id می‌تواند رویدادهای مرتبط را کنار هم قرار دهد.

منبع: https://docs.suricata.io/en/latest/output/eve/eve-json-output.html

## ATT&CK

تاکتیک هدف رفتار و تکنیک روش انجام آن را توصیف می‌کند. در مأموریت این دمو، پیوست فیشینگ T1566.001، اجرای PowerShell T1059.001، دسترسی به اعتبارنامه T1003، RDP T1021.001 و خروج داده روی کانال C2 T1041 بررسی می‌شوند. این ترتیب روایت انتخاب‌شدهٔ درس است؛ چارچوب ترتیب واحدی برای همهٔ نفوذها تعیین نمی‌کند.

منبع: https://github.com/mitre/cti/tree/master/enterprise-attack

این متن یادداشت تألیفی آموزش است. برای جزئیات وابسته به نسخه، مستند کامل مرجع را بخوان.
