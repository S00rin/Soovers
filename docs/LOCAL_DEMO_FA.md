# SooVers Academy 1.0 — دموی تعاملی F5

ZIP را استخراج کن و داخل پوشهٔ SooVers_Demo روی START_WINDOWS.bat دوبار کلیک کن. مرورگر پس از آماده‌شدن سرور باز می‌شود. پنجرهٔ اجرا را هنگام کار باز نگه دار؛ برای توقف Ctrl+C بزن.

اجرا به Node.js نسخهٔ 24 یا جدیدتر نیاز دارد. اجراکنندهٔ ویندوز، Node نصب‌شده یا Node همراه Codex در همین رایانه را پیدا می‌کند. اینترنت و نصب وابستگی برای اجرای سایت ساخته‌شده لازم نیست؛ لینک منابع رسمی آنلاین‌اند.

اجرای دستی:

```bash
node run.mjs --open
```

آدرس پیش‌فرض: http://127.0.0.1:8080/
اگر پورت اشغال است:

```bash
node run.mjs --port 8081 --open
```

برای نمونهٔ جدید: کالبدشکافی ← مدل‌ها ← مسیر ترافیک ← تحلیل لاگ ← سه پروندهٔ عیب‌یابی ← ارزیابی و گزارش.
پیشرفت اجزا، حل پرونده‌ها و پاسخ‌ها روی همان مرورگر ذخیره می‌شود. چرخش دستگاه با کشیدن، بزرگ‌نمایی با اسکرول و انتخاب اجزا با دکمه یا کلیک ممکن است. بدون WebGL هم محتوای متنی و تمرین‌ها قابل استفاده‌اند.

برای جهان قبلی، «جهان متاورسی» را بزن یا آدرس /#tower را باز کن. مسیر برج، پذیرش، تعیین سطح اختیاری، کلاس، pfSense/Suricata، SOC و CTF در دسترس است. برای ورود به کلاس، آزمایشگاه و درس‌ها نیازی به آزمون نیست؛ ارزیابی F5 هم اختیاری است.

همهٔ لاگ‌ها و خروجی‌های میز بررسی F5 ساختگی و آموزشی‌اند. مدل دستگاه شماتیک است. این بسته به دستگاه واقعی، SIEM یا شبکهٔ سازمان وصل نمی‌شود و VM واقعی F5 ندارد.

source سورس کامل و site خروجی ساخته‌شدهٔ همین نسخه است. برای تغییر، source را ویرایش و Build بگیر. راهنمای محصول در source/docs/PRODUCT.md، استقرار Docker در source/docs/OPERATIONS.md و نتیجهٔ اعتبارسنجی محصول در source/docs/VALIDATION_1.0.md آمده است. دمو فقط در مرورگر ذخیره می‌کند؛ برای حساب کاربری و ذخیرهٔ سمت سرور، نسخهٔ Docker را اجرا کنید.
