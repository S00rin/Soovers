# SooVers 0.5 — آکادمی تعاملی F5

ZIP را استخراج کن و داخل پوشهٔ SooVers_Demo روی START_WINDOWS.bat دوبار کلیک کن. مرورگر پس از آماده‌شدن سرور باز می‌شود. پنجرهٔ اجرا را هنگام کار باز نگه دار؛ برای توقف Ctrl+C بزن.

اجرا به Node.js نسخهٔ 22.13 یا جدیدتر نیاز دارد. اجراکنندهٔ ویندوز، Node نصب‌شده یا Node همراه Codex در همین رایانه را پیدا می‌کند. اینترنت و نصب وابستگی برای اجرای سایت ساخته‌شده لازم نیست؛ لینک منابع رسمی آنلاین‌اند.

اجرای دستی:

```bash
node run.mjs --open
```

آدرس پیش‌فرض: http://127.0.0.1:8080/
اگر پورت اشغال است:

```bash
node run.mjs --port 8081 --open
```

برای نمونهٔ جدید: کالبدشکافی ← مدل‌ها ← مسیر ترافیک ← تحلیل لاگ ← سه پروندهٔ عیب‌یابی ← ارزیابی و گزارش.
پیشرفت اجزا، حل پرونده‌ها و پاسخ‌ها روی همان مرورگر ذخیره می‌شود. چرخش دستگاه با کشیدن، بزرگ‌نمایی با اسکرول و انتخاب اجزا با دکمه یا کلیک ممکن است. بدون WebGL هم محتوای متنی و تمرین‌ها قابل استفاده‌اند.

برای جهان قبلی، «جهان متاورسی» را بزن یا آدرس /#tower را باز کن. مسیر قدیمی برج، پذیرش، تعیین سطح، کلاس، pfSense/Suricata، SOC و CTF حفظ شده است.

همهٔ لاگ‌ها و خروجی‌های میز بررسی F5 ساختگی و آموزشی‌اند. مدل دستگاه شماتیک است. این بسته به دستگاه واقعی، SIEM یا شبکهٔ سازمان وصل نمی‌شود و VM واقعی F5 ندارد.

source سورس کامل و site خروجی ساخته‌شدهٔ همین نسخه است. برای تغییر، source را ویرایش و Build بگیر. گزارش بررسی و تغییرات در source/docs/F5_0.5_FA.md و نتیجهٔ آزمون‌های این نسخه در source/docs/VALIDATION_0.5.md آمده است. فایل VALIDATION.md سابقهٔ نسخهٔ قبلی است.
